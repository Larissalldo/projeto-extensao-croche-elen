# projeto-extensao-croche-elen
Projeto de extensão desenvolvido para auxiliar uma artesã local na divulgação e organização de produtos de crochê por meio de ferramentas digitais e um catálogo em Python.
# Projeto de Extensão - Crochê da Elen

## Objetivo
Auxiliar uma artesã local na divulgação e organização de seus produtos utilizando recursos tecnológicos.

## Sistemas de Informação e Sociedade
Este projeto demonstra como a tecnologia pode contribuir para pequenos empreendimentos artesanais por meio da criação de um catálogo digital e da divulgação em redes sociais.

## Produtos
- Bolsas de crochê
- Suplás
- Kits para banheiro
- Porta-garrafas
